What is this repository for?
------------------------------

Test_conda_env is a suite of programs/scripts to test the different conda environements to run the Vnet model. 

The model is mostly tested for stability with different versions of pytorch and python. 

The yml files corresponding to different versions of pytorch and python are created and the list of the conda enviroment is maintained. 

Shell scripts are written out to activate the conda enviroment and test the model for specified data set. all the shell scripts corresponding to various conda enviroment is swarmed on biowulf using the run_test_conda_env.tcsh
